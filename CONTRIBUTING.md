# Guía de Contribución

¡Gracias por tu interés en contribuir a Historia Familiar!

## Cómo Contribuir

### Reportar Bugs

Si encuentras un bug, por favor abre una issue con:
- Descripción clara del problema
- Pasos para reproducirlo
- Comportamiento esperado
- Comportamiento actual
- Tu navegador y SO

### Sugerir Mejoras

Las sugerencias son bienvenidas. Abre una issue con:
- Una descripción clara de la sugerencia
- Por qué sería útil
- Ejemplos de cómo podría funcionar

### Mejorar el Contenido

Puedes contribuir mejorando el contenido del curso:

1. Edita `data/course.json` para mejorar lecciones existentes
2. Agrega nuevas lecciones o módulos
3. Mejora la calidad del contenido
4. Añade recursos y referencias

### Mejoras de Código

Para cambios en el código:

1. Fork el repositorio
2. Crea una rama para tu feature: `git checkout -b feature/nombre-feature`
3. Haz tus cambios
4. Asegúrate que el código sea limpio y funcional
5. Commit: `git commit -am 'Agregar feature: descripción'`
6. Push: `git push origin feature/nombre-feature`
7. Abre un Pull Request

## Estándares

- Mantén el código limpio y comentado
- Respeta el formato existente
- Asegúrate que sea responsive (funcione en móvil)
- Prueba en diferentes navegadores

## Proceso de Revisión

Los Pull Requests serán revisados considerando:
- Calidad del código
- Relevancia para el proyecto
- Compatibilidad
- Documentación

## Preguntas?

Abre una issue con la etiqueta "pregunta" si tienes dudas.

¡Gracias por tu contribución!
